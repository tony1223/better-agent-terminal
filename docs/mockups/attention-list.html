「需要我」清單：示意圖（左側欄版）

前提：左側欄的 workspace 列右邊本來就有一顆 8px 的活動小點（ActivityIndicator），footer 本來就有一個鈴鐺（NotificationBell）。 這個提案不新增任何元件，只是讓這兩個既有的東西多回答一個問題：「哪些 session 在等我？」

現況：小點今天的意思

黃色呼吸 = 最近 10 秒有輸出（在跑）；綠色暗淡 = 曾經有活動但現在沒動；紅色呼吸加「?」= 有工具在等你核准。 問題：「跑完了、你還沒看」和「早就看過了」都是同一顆暗綠點，所以你得一個一個點進去看。鈴鐺有未讀數字，但只算本視窗，而且列表沒告訴你做了什麼。

狀態 A：沒事 / 只有東西在跑

和現在完全一樣。黃點在跑，看過的暗綠，沒活動的沒點。鈴鐺灰色數字只代表「有幾個在跑」，不會閃。

規則整理

情境workspace 列的小點鈴鐺會不會跳東西
沒 agent 在跑、也沒新東西無或暗綠（現況）沒數字不會
有 agent 在跑黃呼吸（現況）灰數字 = 跑中的數量不會
做完、你還沒看亮綠（新）綠數字不會（桌面通知是第 2 點另做）
等核准 / 失敗紅 ?（現況）紅數字不會
你切到那個 workspace亮綠退成暗綠數字減一—
點鈴鐺——現有的清單，多跨視窗、多一行說明、多核准鈕

最小版本：只做「亮綠 vs 暗綠」這一件事，其他都不動。這樣光看左側欄就知道誰做完沒看，成本一天內。
